## Prompt 1：需求

```text
你现在是产品经理和网站信息架构师。

我要为【人物/品牌/产品】制作一个网站。
目标用户是【用户】。
网站目标是【目标】。
现有内容包括【内容】。

先不要选择技术栈，不要写代码。

请输出：
1. 网站的主要用户任务
2. 必须功能与暂缓功能
3. 页面结构
4. 每个页面需要的真实内容
5. MVP完成标准
6. 当前缺失素材
7. 需要我确认的风险
```

## Prompt 2：页面

```text
根据已确认的网站目标和用户任务，自动选择最重要的3个代表页面。
说明每个页面验证的内容结构、导航和核心任务。
不要设计UI，不要选择技术栈，不要写代码。
```

## Prompt 3：可行性预检

```text
只检查当前需求是否存在明显的技术、成本、内容或部署风险。
可以指出哪些需求可能需要前端框架、数据库、CMS或付费服务，
但现在不要选择最终技术栈，不要创建项目。
```

## Prompt 4：DEMO内容

```text
为3个确认页面建立一组统一的轻量DEMO内容。
所有虚构内容必须显示标记DEMO，并登记到DEMO清单。
内容需要足以判断页面长度、图片比例、标题换行和组件状态。
不要建立正式TypeScript Schema，不要写网站代码。
```

## Prompt 5：参考研究

```text
根据网站类型和目标风格选择3–5个设计集合站并实际检索。
整理1–3个最相关案例，分别说明值得参考的是：
布局、字体、色彩、图片处理、组件、导航还是动效。

不要复制源代码、文字、图片、字体或品牌资产。
开源代码必须检查许可证。
如果我已提供参考网站并明确说无需检索，才跳过检索。
```

## Prompt 6：风格探索

```text
使用同一组DEMO内容，为已确认的3个页面提出3种明显不同的视觉方向。
导航、结构、布局、图片风格和交互概念可以不同。

每种风格生成3张1440px宽完整桌面长页图，共9张。
每张图展示完整页面，不只展示首屏。
现在禁止写任何网站实现代码。
```

## Prompt 7：最终UI

```text
根据我从三个方向中选取的元素，先输出一份最终设计配方。
所有字号、行高、间距、宽度、圆角、颜色、边框和图片比例必须明确。

然后生成：
- 3张1440px宽桌面长页
- 3张390px宽手机长页
- 关键区域放大图

优先使用Figma；没有Figma时使用长页图片和完整数值规范。
不要写网站代码。
```

## Prompt 8：动效

```text
UI已经确认。先不要实现代码。

检索动效参考并提供克制、叙事、实验三档方案。
每个动效必须说明：
- 触发条件
- 起始和结束状态
- 位移或缩放数值
- 持续时间
- easing
- 是否跟随滚动
- 移动端降级
- reduced-motion
- 性能风险

最多为3个关键动效制作Figma原型或短样片，其余使用分镜。
```

## Prompt 9：技术与CMS

```text
根据已确认的功能、UI和动效，比较：
1. 原生HTML/CSS/JS
2. Astro
3. Vite + React + TypeScript
4. Vite + Vue
5. Next.js

比较SEO、动效、内容维护、部署、学习、长期维护和首年成本。
根据更新频率和编辑人数判断是否需要CMS。
最后只推荐一个技术栈和一个内容维护方案。
说明出现哪些新需求后才需要升级。
不要创建项目。
```

## Prompt 10：正式Schema

```text
在写页面前建立正式内容Schema、TypeScript类型和示例数据。
要求：
- 稳定ID
- 发布状态和归档状态
- 图片包含路径、宽高、比例、alt、来源
- SEO字段
- DEMO标记
- 必填字段自动校验
- 内容与视觉配置分离
- Web App需要数据库、Auth和RLS设计
页面不得出现pending或空白占位内容。
```

## Prompt 11：代表页面

```text
技术方案已经确认。
只实现一个最有代表性的静态页面，不加复杂动效。
完成后在1440px、1024px和390px宽度截图，与确认稿比较。
列出所有明确数值差异、溢出、断行、比例和键盘问题。
```

## Prompt 12：完整开发

```text
代表页面已通过。扩展全部静态页面并使用真实内容或已登记DEMO内容。
静态页面验收后，每次只实现一种已确认动效。
实现动效时禁止同时修改内容、布局和其他动效。
```

## Prompt 13：生产验收

```text
按照生产发布标准审计网站：
1. 页面、按钮、表单和链接
2. 1440px、1024px、390px
3. 404
4. 图片尺寸、比例、alt和来源
5. 键盘和reduced-motion
6. title、description、canonical、robots、sitemap、JSON-LD
7. noindex
8. 控制台错误
9. 缓存和旧数据
10. RLS与密钥
11. 本地发布包与线上文件

不要因为部署成功就判定完成。
分开列出阻断发布问题和非阻断优化。
```

## Prompt 14：复盘

```text
根据完整项目记录生成自媒体内容包：
- 时间线
- 关键Prompt
- 做对和踩坑
- 前后对比
- 技术与CMS选择
- 成本
- 5个选题
- 每个选题的标题、钩子、大纲和配图

不得虚构结果、指标或用户反馈。
```
